---

## Reporting a Vulnerability

The VEYORA team takes the security of our software and user data very seriously.

If you believe you have found a security vulnerability in VEYORA (either in the Flutter mobile application or the Node.js backend proxy), please **do not disclose it publicly** via GitHub Issues.

Instead, please send an email with full details to:

📧 **security@trydigitalsolution.com** (or pankaj@trydigitalsolution.com)

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- Details regarding the affected component (e.g. Local Storage, Proxy Auth, Rate Limiter).

### What to Expect
- **Acknowledgment**: You will receive an initial response within 48 hours acknowledging receipt of your report.
- **Assessment**: We will investigate and assess the vulnerability and keep you informed of our progress.
- **Fix & Disclosure**: Once a fix is verified, a patch release will be published along with appropriate security disclosure notes and attribution.
